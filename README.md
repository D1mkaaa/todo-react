# 🚀 Todo App (React + Vite)

Современное и удобное приложение для управления задачами (To-Do List), созданное на базе **React** и сборщика **Vite**. Проект помогает эффективно планировать день, добавлять, отслеживать и удалять текущие задачи.

## 🔗 Демонстрация
[Посмотреть работающее приложение live](https://d1mkaaa.github.io/todo-react/)

## ✨ Особенности проекта
*   ➕ **Добавление задач:** Быстрое создание новых пунктов плана.
*   ✅ **Отметка о выполнении:** Возможность зачеркивать сделанные дела.
*   🗑️ **Удаление:** Очистка списка от ненужных или выполненных задач.
*   📱 **Адаптивный интерфейс:** Корректное отображение как на компьютерах, так и на мобильных телефонах.
*   🚫 **Страница 404:** Настроенная кастомная страница ошибок `404.html` для перенаправления.

## 🛠️ Технологии
*   **React.js** (Компоненты, Хуки `useState` / `useEffect`)
*   **Vite** (Быстрый сборщик проекта)
*   **JavaScript (ES6+)**
*   **HTML5 & CSS3** (Разметка и стили в папке `assets`)

## 🚀 Как запустить проект локально

Чтобы развернуть проект на своем компьютере, выполните следующие шаги:

### 1. Клонирование репозитория
```bash
git clone https://github.com/D1mkaaa/todo-react.git
cd todo-react
```

### 2. Установка зависимостей
Убедитесь, что у вас установлен [Node.js](https://nodejs.org). Затем выполните команду:
```bash
npm install
```

### 3. Запуск сервера разработки
```bash
npm run dev
```
После этого терминал выдаст локальную ссылку (обычно `http://localhost:5173`), по которой можно открыть приложение в браузере.

### 4. Сборка для продакшена (если необходимо)
```bash
npm run build
```
